## 下载

- Apple Silicon（M 系列芯片）：`SimBox_v2.2.0_arm64.dmg`
- Intel：`SimBox_v2.2.0_x86_64.dmg`

从本版本起按架构分别发布，安装包更小；已安装 2.1.0 的用户会通过自动更新收到与本机匹配的版本。

## 新功能

- app 子菜单新增：在 Finder 中定位 `.app` 安装包、打开 UserDefaults plist、复制 bundle identifier
- 模拟器标题新增子菜单：在 Finder 中打开设备目录、复制 UDID
- 超过 5 台的模拟器收进 “More Simulators” 子菜单，不再直接丢弃
- App Group / App Extension 条目显示类型图标

## 修复

- macOS 27 上菜单里的 app 图标不显示
- 重置 app 数据会删掉 Documents / Library / tmp 目录本身，导致 app 之后无法写入；现在只清空内容并保留容器结构，失败时给出提示
- 已删除（isDeleted）的模拟器仍出现在列表中
- 只装了系统 app 的模拟器占用 “最近 5 台” 名额，导致有内容的模拟器被挤掉
- app 名称显示 CFBundleName 而非桌面上的显示名称；版本号改为 `1.2.0 (45)` 形式
- iPad 应用图标文件名匹配错误、优先使用最小尺寸图标
- iTerm / Commander One / Realm Studio 安装在 ~/Applications 等位置时识别不到；Commander One 未安装却显示入口
- 开机自启需要用户授权时没有任何提示，现在会跳转到“系统设置 › 登录项”
- 每次展开菜单都会对每个 app 全量扫描安装目录，app 多时明显卡顿；子菜单改为展开时才构建，图标加缓存

## 其他
